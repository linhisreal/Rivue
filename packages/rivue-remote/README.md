# RivueRemote

Request/response and events between client and server over RemoteEvents, with payload checks and
per-player rate limits. A companion to [Rivue](https://github.com/linhisreal/Rivue), which only
does UI. It doesn't depend on Rivue.

```lua
local Remote = require(ReplicatedStorage.Packages.RivueRemote)
```

Docs: https://linhisreal.github.io/Rivue/api/remote
