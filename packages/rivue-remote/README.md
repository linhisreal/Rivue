# RivueRemote

Request/response and events between client and server over RemoteEvents, with payload checks and
per-player rate limits. It works with [Rivue](../../README.md) but doesn't need it.

```lua
local Remote = require(ReplicatedStorage.Packages.RivueRemote)
```

Docs: [RivueRemote API](../../docs/api/remote.md)
