# Rivue DevTools

A Studio plugin that lists the Rivue components on screen during a playtest: their props, their
state, and how many times they've rendered. Components that just re-rendered show in orange, and
clicking one selects its root in the Explorer.

Download `RivueDevTools.rbxm` from a [release](https://github.com/linhisreal/Rivue/releases) into
your Plugins folder, then set `app.config.devtools = true` in your game before `app:mount()`.

Guide: https://linhisreal.github.io/Rivue/DEVTOOLS
