# Guide chapters

Chapters 1–11 are meant to be read in order. Chapters 12–16 are advanced and stand alone.

| | Chapter | You'll learn |
|---|---|---|
| 1 | [Introduction](guide/01-introduction.md) | what Rivue does, your first component, `setup` + `render` |
| 2 | [State](guide/02-state.md) | `ref`, `reactive`, `computed`, what gets tracked, changing lists |
| 3 | [Describing UI](guide/03-describing-ui.md) | `h()`, every kind of prop, conditions, lists and keys |
| 4 | [Components](guide/04-components.md) | props down and events up, slots, the lifecycle |
| 5 | [Forms and input](guide/05-forms-and-input.md) | `model`, `defineModel`, directives |
| 6 | [Styling and layout](guide/06-styling-and-layout.md) | style classes, `layout` and `flex`, different devices |
| 7 | [Effects and animation](guide/07-effects-and-animation.md) | watchers, cleanup, update timing, transitions, springs |
| 8 | [Sharing state and the server](guide/08-state-and-server.md) | provide/inject, store modules, `Remote` |
| 9 | [Performance and debugging](guide/09-performance-and-debugging.md) | what's slow, finding out why, common mistakes |
| 10 | [Organising a project](guide/10-organising-a-project.md) | folders, component anatomy, splitting, composables |
| 11 | [Style rules](guide/11-style-rules.md) | the habits that prevent bugs and keep code readable |
| | **Advanced** | |
| 12 | [Writing composables](guide/12-writing-composables.md) | sharing logic between components, cleanup, a debounced search, loading data |
| 13 | [Component patterns](guide/13-advanced-components.md) | tabs, shared behaviour with different looks, switching screens, modals |
| 14 | [Organising state](guide/14-state-architecture.md) | where state should live, stores, server data, instant purchases |
| 15 | [Performance in depth](guide/15-performance-in-depth.md) | what makes UI slow, finding the cause, which fix to try |
| 16 | [Testing UI](guide/16-testing-ui.md) | testing logic, mounting components in tests, clicking from code |
