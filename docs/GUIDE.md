# Guide chapters

Read chapters 1 to 11 in order; each one builds on the last. Chapters 12 to 17 stand alone, so
open them when you need them.

Know Vue already? Read [Rivue for Vue developers](VUE.md) first, then skip to chapter 6, where
Rivue differs most.

| | Chapter | Covers |
|---|---|---|

| 2 | [State](guide/02-state.md) | `ref`, `reactive`, `computed`, what gets tracked, changing lists, `toRefs` |
| 3 | [Describing UI](guide/03-describing-ui.md) | `h()`, every kind of prop, conditions, lists and keys |
| 4 | [Components](guide/04-components.md) | props down and events up, function components, slots, the lifecycle |

| 7 | [Effects and animation](guide/07-effects-and-animation.md) | watchers, cleanup, update timing, transitions, springs |
| 8 | [Sharing state and the server](guide/08-state-and-server.md) | provide/inject, store modules, RivueRemote requests, events and replicated state |
