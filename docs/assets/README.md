# Assets

All the images used in the README and the docs.

- The Rivue icon and the Guide logo are in this folder.
- `diagrams/` has the pictures from the guide and the API pages.
- `badges/` has the badges at the top of the README.
- `web/` has the favicons for the docs site.

<img src="./guide-lockup.webp" height="64" alt="Rivue Guide">

## Logo files

| File | For |
|---|---|
| `icon` | the Rivue icon |
| `guide-icon` | the Guide icon, 33 px and bigger |
| `guide-icon-small` | the Guide icon at 32 px or smaller |
| `guide-lockup` | icon and name, light backgrounds |
| `guide-lockup-dark` | icon and name, dark backgrounds |
| `guide-lockup-stacked` | icon above the name |
| `guide-icon-black`, `guide-icon-white` | one colour |

Colours: blue `#1F6FEB`, mint `#7EE8C0`, white, and `#1F2328` for dark text. The font is Inter
Display (SIL Open Font License), already turned into shapes, so you don't need it installed.

Please don't recolour or stretch the logos.

The original SVGs aren't in the repo. Ask the maintainer if you need them.
