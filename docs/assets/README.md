# Assets

Images used by the README, the docs and the docs site.

| Path | What it is |
|---|---|
| `icon.webp` | the Rivue icon |
| `guide-icon.webp` | the Guide icon |
| `license-lockup.webp` | the header of the license files |
| `packages/` | one icon per package |
| `badges/` | the badges at the top of the README |
| `diagrams/` | pictures for the guide and the API pages |
| `web/` | favicons and the site logo; the docs site serves this folder as its public folder |

Colours: blue `#1F6FEB`, mint `#7EE8C0` and `#1F2328` for dark text. The package icons use the
same tile in purple `#8250DF` (RivueRemote), raspberry `#D63864` (RivueRouter) and charcoal
`#2D333B` (RivueDevTools). Text in the images is Inter Display (SIL Open Font License), already
turned into shapes.

Don't recolour or stretch the logos. The source SVGs aren't in the repo; ask the maintainer for them.
